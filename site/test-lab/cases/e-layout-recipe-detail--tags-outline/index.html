여름 면 요리

들기름 막국수

차갑고 고소한 15분 한 그릇

  • 2인분
  • 15분
  • 난이도 쉬움

이 요리에 대하여

더운 날 입맛이 없을 때 가장 자주 만드는 면 요리입니다. 불 앞에 서 있는 시간이 10분도 되지 않고, 재료도 대부분 집에 있어요.

한눈에 보기

준비 시간
5분
조리 시간
10분
분량
2인분

재료

  • 메밀면 200g

    생면이면 더 좋아요

  • 들기름 3큰술
  • 진간장 2큰술

    입맛에 따라 조절

  • 구운 김 2장
  • 깨소금 1큰술

만드는 순서

  1. 면 삶기

    끓는 물에 면을 넣고 포장지 시간보다 30초 덜 삶습니다.

  2. 찬물에 헹구기

    찬물에 비벼 씻어 전분기를 빼고 물기를 꼭 짭니다.

  3. 양념 섞기

    들기름과 간장을 섞어 면에 먼저 버무립니다.

  4. 올려 내기

    구운 김을 부숴 올리고 깨소금을 뿌립니다.

요리 팁

들기름은 열에 약해 향이 날아갑니다. 불을 끈 뒤 맨 마지막에 둘러 주세요.
