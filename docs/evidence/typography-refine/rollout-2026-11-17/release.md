## 반영한 타이포그래피

가장 뚜렷했던 큰 한글 제목의 과한 음수 자간과 좁은 행간을 공통 규칙에서 교정했습니다. 큰 제목 자간 하한 −0.02em, 역할별 행간 하한 1.2~1.35, 크기 상한과 일부 라틴 서체 짝을 조정했습니다. 2.1·2.2 입력의 기존 출력은 유지됩니다.

이전 전후 측정은 85예시 × 두 폭 = 170뷰이며, 한글 주제목 자간 ≤ −0.03em은 데스크톱 58→0·모바일 59→0, 두 줄 이상 제목의 행간 <1.15는 14→0·15→0이었습니다. 비교 24장과 확대 9장은 기획이 직접 열람했습니다. 자동 수치 개선을 모든 화면의 미감 개선으로 해석하지 않았습니다.

## 인증 경로와 이전 실패 해소

사용자가 지정한 Keychain 항목 `vercel-cli-token`을 메모리 안에서 읽어 `VERCEL_TOKEN` 환경변수로 CLI에 전달했습니다. 계정 확인은 winterholic / exit 0, 배포와 inspect도 성공했습니다. 토큰은 화면·로그·산출물에 출력하거나 파일로 저장하지 않았습니다. 공식 Node 실행 모드와 업데이트 알림 생략을 사용했고, 기존 보호 경로를 쓰거나 샌드박스 권한을 변경하지 않았습니다. Keychain 보관은 CLI 기본 로그인 정보와 별도였으며, 지정된 자격증명을 명시적으로 연결한 경로로 해결했습니다.

이전 `deployment-attempt.json`과 `diagnostic.md`는 실패 시점 이력으로 보존합니다. 현재 결과는 이 디렉터리의 `deployment.json`, `production.json`, `production-version-after-deploy.json`, `production-browser.json`, `deploy-cli.log`, `ci.json`이 정본입니다.
