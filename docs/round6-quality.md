# 6차 품질 라운드 기록 (2026-10-21)

폭을 늘리는 라운드가 아니다. 사용자가 `/combos/`를 직접 보고 찾은 네 가지 원인(패딩이 엉망인 레이아웃, 고정된 타이포, 텍스트 자리가 아닌 곳의 큰 글자, 1테마-1템플릿)을 **측정으로 확인하고 구조에서 고쳤다**. 수치는 모두 이 저장소의 명령으로 다시 낼 수 있다. (같은 날 앞서 나간 `docs/round6.md`는 전체 조합 갤러리 기록이다. 이 문서는 그 갤러리를 본 사용자의 평에 대한 개선이다.)

## 1. 진단: 기존 시험이 통과하는데 왜 못생겼나

4차 간격 실측과 5차 글줄 실측은 **부분의 일관성**을 쟀다. 못생긴 조합은 부분마다는 규칙을 지키고 **구성**이 잘못됐다. 그래서 세 번째 프로브 `scripts/design-qa/layout-probe.mjs`를 만들어 구성의 품질을 쟀다.

| 코드 | 무엇을 재나 | 사용자가 말한 증상 |
|---|---|---|
| EMPTY_CELL | 표면 상자의 위·아래·내용 사이 빈 공간이 96px 이상이고 상자 높이의 38% 이상 | "텍스트가 들어갈 자리가 아닌 곳"의 반대편: 자리는 큰데 텍스트가 구석에 박힘 |
| BIG_NARROW | 24px 이상의 글자가 칸 폭 8em 미만에 3줄(12em 미만에 4줄) | 좁은 칸에 박힌 큰 글자 |
| HIER_INVERT | 섹션 머리말이 페이지 h1보다 크거나 카드 제목이 섹션 머리말 이상 | 제목 위계가 뒤집힘 |
| GRID_ORPHAN | 같은 크기 카드 격자의 마지막 줄에 한 칸만 남음 | 어설픈 배치 |
| TIGHT_ROW | 높이 48px 미만의 표면 줄(일정·목록)의 글자가 가장자리 8px 안 | 패딩이 엉망 |
| MEASURE | 한 줄 수용 글자 수(글자 종류별 평균 폭 환산)가 14~75자 밖 | 한 줄 길이 |
| BAND_ASYM · EDGE_VIEW | 띠 안 내용의 위·아래 여백 비대칭, 화면 가장자리 16px 안의 글자 | 패딩 |

전수 진단 결과와 등급 분포는 `docs/diagnosis-round6.md`에 있다(`node scripts/design-qa/diagnose.mjs` → `grades.mjs`).

찾은 원인(진단 전 코드 기준):

1. **구성 변형이 서로의 조건을 모른 채 곱해졌다.** `intro:center`(가운데 정렬 머리말)가 조합의 절반이었고 대시보드·문서·데이터 화면에도 붙어 제목만 가운데 서고 본문은 왼쪽인 화면이 됐다. 지표·인용·진행률이 섞인 벤토를 `features:grid`로 바꾸면 같은 높이로 늘어나 칸 아래가 270px 비었다(이 옵션이 든 조합의 80%가 EMPTY_CELL). `columns:two`는 3개 카드를 2열에 넣어 마지막 줄에 한 칸을 남겼다(조합의 28.5%가 마지막 줄 고아).
2. **벤토 첫 칸이 내용과 무관하게 2×2였다.** 글만 있는 카드가 420px 비어 보였다. 인용문 26px이 150~280px 칸에 3줄로 접혔다.
3. **부품이 크기와 열 수를 직접 정했다.** font-size 값이 58종, 격자 열 수는 뷰포트 미디어 쿼리로만 줄었다(사이드바가 있으면 뷰포트가 넓어도 칸이 좁다).
4. **일정 목록 줄의 안쪽 여백이 3px**이었다(달력 칸의 조각 스타일이 목록에 새어 나옴).
5. 서체는 스택 이름 8종, 비율·자간·행간은 모든 서체가 같았다. 한글을 −0.035em까지 조이는 값이 전부에 적용됐다.

## 4. 구조: 주제 → 템플릿 → 레이아웃

- **컨셉 17개**(`src/catalog/concepts.mjs`): 제품·SaaS, 개발자 도구, 업무·운영, 금융, 카페·식음, 이커머스·뷰티, 여행·부동산, 건강·운동, 교육·학교, 문화·전시·기록, 뉴스·매거진·글, 브랜드·에이전시, 이벤트·웨딩, 공공·비영리, 에너지·산업, 게임·엔터, 모바일 앱. 컨셉마다 템플릿 7~16개와 look(테마+서체+선택적 테마 변형) 3~4벌. 템플릿은 평균 컨셉 둘 이상에 속하고 템플릿마다 시각 언어 선택지가 3개 이상이다.
- **레이아웃**은 템플릿마다 구성 변형(슬롯 × 옵션)으로 고른다. 새 구성 3종(섹션 머리말 가운데, 질문 좌우 분할, 단계 카드)을 마케팅 페이지에 더했다.
- **갤러리**: 컨셉 선택(템플릿 필터 + 첫 look 적용), look·서체 선택, 실험 구성 포함 토글(기본 꺼짐), 카드의 실험 표시와 이유. 주소: `?concept=&look=&type=&exp=1`.

**재설계·폐기·신규 레이아웃.**

- 재설계 5곳: 벤토(시각 요소만 2×2, 줄 채움 배치표, 컨테이너 기준 열 수), 격자 흐름(그리드·요금제·기능 목록·갤러리·단계·팀·메뉴판·지표/미디어 카드 8개 부품이 같은 규칙), 인용문(칸 폭에 따른 크기), 일정 목록(안쪽 여백), 섹션 머리말 2열 전환(뷰포트 → 컨테이너 폭).

## 6. 하지 않은 것·한계

- **웹폰트.** 생성 페이지가 `default-src 'none'` CSP의 자기완결 문서라 싣지 않았다. 한글 서체의 차이는 시스템 서체(Apple SD Gothic Neo·AppleMyungjo 등)의 범위에서 나고, 산세리프 프리셋끼리는 서체 모양보다 굵기·자간·비율·행간으로 구분된다. 후보와 라이선스(OFL)는 `docs/typography.md`.
- **미감 전수 확인.** 등급은 측정 가능한 결함의 유무다. 대표 화면은 눈으로 봤고(전후 스크린샷), 전 조합을 사람이 보지는 않았다.
- **폰트 차이.** 등급은 macOS 폰트로 얻었다. Linux CI는 표본으로 다시 잰다.
- **Safari·실기기**, `@container`·`:has()`가 없는 구형 브라우저의 대체 열 수 동작은 확인하지 못했다(Chromium 에뮬레이션만).
- 진단의 렌더는 조합당 기본 테마 + 돌려 쓰는 테마 1개다. 54개 테마 × 전 조합은 재지 않았다(기본 구성 85개 × 54테마는 개발 중 별도로 쟀다).
