# ADR 0005 · 기존 역할과 flow를 맥락 결정표로 연결한다

- 상태: 채택 · 2026-11-16
- 근거: `../context-audit.md`의 변경 전 실측과 코드 추적

독립 type/spacing/layout 계약을 재구현하지 않는다. 작은 선언형 사실 비교 표로 기존 역할을 선택하고, 콘텐츠 폭 예산을 기존 bestCols에 공급한다. 충돌은 필드별 priority로 해결하며 동순위 불일치는 명시적 오류다. 실제 컨테이너 폭은 CSS, 폭 필요량은 컴파일 시 사실에서 분리해 결정한다. generated attributes는 컴파일러가 소유하며 Blueprint에서 받지 않는다.

새 범용 조건 언어는 데이터 검증과 디버깅 비용을 늘린다. 화면마다 CSS 예외를 더하면 같은 실패가 다른 표본에 남는다. 외부 시스템의 수치·자연어 스킬·LLM 호출은 현재 kit의 실행 규약을 대체하지 않는다. 공식 원칙은 설계 근거, 코드·토큰·테스트는 실행 근거다.

카탈로그 2.2.0과 composition 1.0.0으로 고정한다. 2.1.0은 당시 경로를 보존하고 85개 템플릿의 전체 결과 hash를 대조한다. 신규 정책은 명시적인 catalogVersion 변경으로만 채택한다. 이전 ADR의 버전 불일치 거부 원칙에 **문서화된 2.1 호환 창**을 추가한 것이다. 소비자가 카탈로그를 수정할 권한과 Blueprint를 조립할 권한은 계속 분리한다.

추적 정보는 `manifest.design`에 노드 경로·사실·적용 규칙·필드별 승자·파생 예산으로 남긴다. 검증기는 입력을 고치지 않는다. 결정적 결과와 실제 시각 개선은 각각 별도 증거를 요구한다. 브라우저 검사 지적이 0이어도 사용자 승인·전체 미감 완료로 기록하지 않는다.
