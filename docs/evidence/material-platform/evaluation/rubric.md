# C단계 사람 평가 기준

## 평가 단위와 절차

한 행은 한 화면의 한 폭이다. 같은 브라우저 배율에서 화면 전체를 훑고, 점수를 먼저 독립적으로 기록한 뒤 근거와 개선안을 적는다. 검사기 결과와 profile 이름은 점수 판단이 끝날 때까지 참고하지 않는다. 서로 다른 업무 맥락의 상대 순위가 아니라 각 화면의 목적 적합성을 채점한다.

| ID | 표본 | 모바일 | 데스크톱 |
|---|---|---|---|
| erp | 주문·재고 운영 | 390px | 1280px |
| commerce | 상품 목록 | 390px | 1280px |
| saas | 제품 소개·가입 | 390px | 1280px |
| analytics | 데이터·재무 분석 | 390px | 1280px |

가능하면 평가자 2명 이상이 독립 평가한다. 평가자 수, 날짜, 화면 ID, 폭, 브라우저/OS를 기록한다. 불일치를 평균만으로 덮지 않고 항목별 점수와 근거를 함께 남긴다. 평가가 완료되기 전 결과 상태는 `미평가`다.

## 공통 1–5점 척도

- **1 — 심각한 문제:** 목적 수행을 막거나 핵심 정보를 찾기 어렵게 하는 결함이 반복된다.
- **2 — 부족:** 주요 결함이 눈에 띄고 화면 이해나 신뢰를 방해한다.
- **3 — 사용 가능:** 핵심 과업은 수행되지만 한두 가지 분명한 개선점이 있다.
- **4 — 좋음:** 위계와 균형이 안정적이며 눈에 띄는 방해가 거의 없다.
- **5 — 매우 좋음:** 목적에 정확히 맞고 작은 화면과 큰 화면 모두 정돈되어 있으며 추가 수정 필요가 거의 없다.

## 평가 항목

| 항목 | 무엇을 본다 |
|---|---|
| 정보 위계 | 제목, 요약, 핵심 수치, 다음 행동을 빠르게 구별할 수 있는가 |
| 균형 | 밀도와 여백, 정렬, 구역 크기가 목적에 맞고 한쪽으로 쏠리지 않는가 |
| 타이포그래피 | 글자 크기, 굵기, 행간, 줄바꿈과 숫자 판독성이 안정적인가 |
| 색 | 대비, 강조, 상태 색이 구분되고 색만으로 의미를 강요하지 않는가 |
| 일관성 | 간격, 모서리, 컨트롤, 카드와 표 표현이 화면 안에서 일관적인가 |
| 콘텐츠 적합성 | 재료의 형태와 실제 업무 내용이 맞고, 목업·장식이 의미를 왜곡하지 않는가 |

항목 점수는 합산해 단일 품질 보증값으로 쓰지 않는다. 최저점과 그 근거, 화면에서 관찰한 구체 요소를 먼저 읽는다. 구조 검사 통과나 SHA 결정성은 이 평가를 대체하지 않는다.

## 비교 조건

- 모바일 폭 390px, 데스크톱 폭 1280px, 높이 900px.
- 비교 표본: `../assembled/<id>/index.html`의 네 조립 화면. 고정된 같은 화면 폭으로 비교하고 브라우저 확대율은 100%로 둔다.
- 사람이 화면을 보기 전에 이미지 생성물이나 검사기 점수로 표본 순서를 바꾸지 않는다.
- 이 자료에는 사람 평가 점수가 없다. `record-template.csv`는 공란 양식이다.
