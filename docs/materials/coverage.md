## 검증 결과와 범위

- 컨트롤 허용·금지 조합은 `tests/material-components.test.mjs:51`의 전수 순회 대상만 범주별로 집계한다. 컴포넌트 간 조합으로 곱하지 않는다.
- 차트 프리셋은 `tests/chart-presets.test.mjs:63`에서 프리셋 예시를 검증한다. 예시 수는 속성 조합 수로 합산하지 않는다.
- B단계 대표 화면: 8건 중 8건에서 error/warn 발견이 없어 100.0% 통과다. info 2건은 의도된 스크롤 영역이다. 근거: `docs/evidence/material-platform/layout/report.json`, 실행 정보: `docs/evidence/material-platform/layout/run.json` (소스 revision `5b607d374bbc4f168818c96f40db6af7296187ce`). 범주별 재료 분모가 없어 이 결과를 범주별 비율로 나누지 않는다.
- A단계는 `npm run verify`의 정적 검사, C단계 사람 평가는 미평가다. 각 범주에 대응하는 A단계 분모가 없어 범주별 품질 통과율은 **미확인**이다.
- 상태·변형 커버리지는 재료 계약에 선언된 값과 전이만 센다. 실제 구현이 계약에 빠진 경우는 이 수치에 드러나지 않으므로 후속 과제에서 계약과 코드를 대조한다.

기계용 전체 값과 근거 경로: [coverage.json](../evidence/materials/coverage.json). 집계 규칙: `src/materials/contract.mjs`, `src/materials/registry.mjs`.
